# 实验助手 · 设计文档 v0.1

2026-09-16 · M1 已实现

## 1. 技术架构

- **技术栈**：Python 3.11+ · PySide6 (Qt6) · SQLite (WAL) · python-markdown · PyInstaller
- **运行形态**：单进程单窗口。主线程 UI + 三个 QTimer：秒级时钟、30 秒跨日检测、30 秒提醒扫描；天气走 QNetworkAccessManager 异步请求，不阻塞 UI，失败不影响核心功能
- **数据**：全部本地（data/lab.db、data/images、data/files、data/backups），无云服务；删除 data/ 即重置全部数据，靠备份防丢失
- **打包兼容**：代码通过 `config.is_frozen()` 区分源码/打包环境；数据目录在打包后位于 exe 同级，资源目录在 `_MEIPASS`

## 2. 数据库设计

**时间约定**：全部存本地时间字符串。计划时间 `YYYY-MM-DD HH:MM`，记录时间/时间戳 `YYYY-MM-DD HH:MM:SS`。
`planned_end` 由 `planned_start + duration_min` 自动计算并冗余存储，编辑时自动重算。

### 2.2 枚举与中文映射

| 域 | 值 → 中文 |
|---|---|
| 实验状态 | planned 未开始 · running 进行中 · done 已完成 · failed 失败 · paused 已暂停 · cancelled 已取消 |
| 优先级 | high 高（红）· medium 中（琥珀）· low 低（灰） |
| 提醒类型 | advance 提前提醒 · on_time 到点提醒 |
| 规划项状态 | planned 未开始 · converted 已转实验 · done 已完成 · cancelled 已取消 |

### 2.3 关键约定

- **提醒去重**：提醒服务每 30 秒扫描一次；触发前先 `INSERT OR IGNORE` reminder_log，保证不重复。到点提醒窗口期为计划时间起 5 分钟（错过仍补提醒）。编辑计划时间时删除该实验的 reminder_log 重新武装
- **图片**：插入/拖拽/粘贴的图片复制到 data/images/（文件名含时间戳+随机），数据库只存相对路径；导出周报时拼接绝对路径
- **备份**：lab.db + images/ + files/ 打 zip 到 data/backups/backup_时间戳.zip；恢复前先校验 zip 内数据库可打开，再覆盖并重启
- **结转**（可选功能，设置开关）：跨零点时，昨天未完成（planned/running）的实验 planned_start 日期平移到今天，时间不变，planned_end 重算，并在今日记录中追加一条说明

## 4. UI 设计说明

### 4.1 配色（需求规定 + 扩展）

### 4.2 组件规范

- **卡片**：圆角 12px + 1px 边框 + 阴影（亮色 rgba(15,23,42,0.09)，暗色 rgba(0,0,0,0.35)），QGraphicsDropShadowEffect 实现
- **状态徽章**：胶囊形，浅色底 + 状态色文字（进行中=主色、完成=绿、失败=红、暂停=琥珀）
- **时间线**：左侧竖线 + 圆点节点，按 record_time 倒序
- **进度环**：QPainter 自绘弧形进度（仪表盘 / 周报）
- **拖拽高亮**：拖入图片时卡片边框变主色 + 浅色底（M3）；规划跨天拖拽目标列高亮（M4）
- **动画**：页面切换 120ms 淡入（QGraphicsOpacityEffect + QPropertyAnimation）
- **字体**：Microsoft YaHei UI；正文 14px，页面标题 20px/700，时钟 22px/700
- **图标**：本地 SVG（原创 stroke 风格、24 网格、currentColor 占位），运行时按主题换色渲染，支持高 DPI；导航图标用 QIcon Off/On 状态实现选中变色
- **空状态插画**：assets/illustrations/ 原创简约 SVG（避免第三方插画许可问题）
- **主题**：QSS + QPalette 双轨切换，持久化到 settings.theme，顶栏快捷切换 + 设置页
